The `@kicbac/nextjs` package adds server-side helpers for the Next.js App Router. Use `createKicbacRouteHandler` to accept tokenized payments and `kicbacWebhookHandler` to verify and process signed webhook events.

Install:

```bash
pnpm add @kicbac/nextjs
```

## Charge route

`createKicbacRouteHandler` requires exactly one amount strategy.

```ts app/api/kicbac/route.ts
import { createKicbacRouteHandler } from "@kicbac/nextjs/server";

export const runtime = "nodejs";

export const { POST } = createKicbacRouteHandler({
  amount: "49.99"
});
```

Use `amountResolver` for cart lookups:

```ts
export const { POST } = createKicbacRouteHandler({
  amountResolver: async ({ body }) => {
    const cartId = String(body.metadata?.cartId ?? "");
    return await lookupCartTotal(cartId);
  }
});
```

## Webhook route

```ts app/api/kicbac/webhook/route.ts
import { kicbacWebhookHandler } from "@kicbac/nextjs/server";

export const runtime = "nodejs";

export const { POST } = kicbacWebhookHandler({
  "transaction.sale.success": async (event) => {
    console.log(event.event_id);
  }
});
```

The helper streams the exact raw bytes through a size-limited reader before verifying the signature.
