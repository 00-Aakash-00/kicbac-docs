---

The `@kicbac/themes` package provides a `createTheme` helper and a `defaultTheme` export so you can define your brand appearance once and pass the same object to any Kicbac browser SDK. The brand defaults use Inter, indigo `#141442`, accent `#f04ac4`, and the Kicbac CTA gradient.

Install:

```bash
pnpm add @kicbac/themes
```

If the registry returns `not found`, use the [verified, pinned source fallback](/sdk/source-install).

Use the themes package when you want the same appearance object across browser SDKs.

```ts
import { createTheme, defaultTheme } from "@kicbac/themes";

const appearance = createTheme({
  variables: {
    colorPrimary: "#f04ac4"
  }
});
```
