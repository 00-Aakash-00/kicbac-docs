The `kicbac` Python package provides both synchronous and asynchronous clients for the Kicbac payment gateway. Declines return `ok=False` and are not raised as exceptions; `response=3` errors raise `APIError` subclasses from `kicbac.errors`.

Install with pip:

```bash
python -m pip install kicbac
```

If the registry returns `not found`, use the [verified, pinned source fallback](/sdk/source-install).

## Sync client

```python
from kicbac import Kicbac

client = Kicbac()  # reads KICBAC_SECURITY_KEY

result = client.transactions.sale(
    amount="49.99",
    payment_token="00000000-000000-000000-000000000000",
)

if result.ok:
    print(result.transaction_id)
else:
    print(result.response_code, result.message)
```

## Async client

```python
from kicbac import AsyncKicbac

async with AsyncKicbac() as client:
    result = await client.transactions.sale(
        amount="49.99",
        payment_token="00000000-000000-000000-000000000000",
    )
```

## Available namespaces

Both clients expose the same resource layout. Use `transactions` for `sale`,
`authorize`, `credit`, `validate`, `offline`, `capture`, `void`, `refund`,
`update`, and `complete_partial_payment`;
`customers` for vault records, billing records, and stored-payment charges;
`plans` and `subscriptions` for recurring billing; `invoices` for invoice
operations; `products` for Product Manager create/update/delete; and `query`
for transaction, customer, subscription, plan, and
invoice lookups. Use `query.raw()` for a read-only report type without a typed
model; the client supplies `security_key` and returns the body unchanged.

`capture` requires an amount. Pass `payment="check"` on an ACH void, refund,
or update. `complete_partial_payment()` fixes `partial_payments` to
`payment_in_full` for the referenced split-tender chain.

## Inline subscription plan

Pass exactly one saved `plan_id` or an inline `plan`. Inline plans accept a day
frequency or a month frequency paired with a day of month.

```python
subscription = client.subscriptions.create(
    plan={"amount": "29.00", "payments": 12, "day_frequency": 30},
    payment_token="00000000-000000-000000-000000000000",
)
```

## Product Manager

```python
product = client.products.create(
    sku="SKU-100",
    description="Example product",
    cost="19.99",
    currency="USD",
)

if not product.ok or not product.product_id:
    raise RuntimeError("Product was not created")

# Update and delete take product_id as the first positional argument.
client.products.update(
    product.product_id,
    description="Updated product name",
    cost="24.99",
)
client.products.delete(product.product_id)
```

## Webhooks

```python
from kicbac import construct_event

event = construct_event(raw_body, signature_header, signing_key="whsec_test_kicbac_8675309")
```

Declines return `ok=False`; they are not exceptions. `response=3` raises `APIError` subclasses.
