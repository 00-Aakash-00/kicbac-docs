The `@kicbac/js` package loads Kicbac.js in the browser and lets you mount PCI-safe hosted card fields into your own DOM elements. Call `session.tokenize()` to exchange card data for a `payment_token` you can send to your server.

Install:

```bash
pnpm add @kicbac/js
```

## Load Kicbac.js

```ts
import { loadKicbac } from "@kicbac/js";

const kicbac = await loadKicbac(import.meta.env.VITE_KICBAC_TOKENIZATION_KEY);
if (!kicbac) {
  throw new Error("Kicbac.js is only available in the browser.");
}
```

## Create a card field session

```ts
const session = kicbac.createFieldSession({
  fields: {
    ccnumber: { selector: "#card-number", placeholder: "Card number" },
    ccexp: { selector: "#card-expiry", placeholder: "MM / YY" },
    cvv: { selector: "#card-cvv", placeholder: "CVV", display: "required" }
  },
  onChange: (_fields, isValid) => {
    document.querySelector("button")?.toggleAttribute("disabled", !isValid);
  }
});

const token = await session.tokenize();
console.log(token.token);
```

Kicbac.js is a page-wide singleton. Destroy a session before mounting another one.
