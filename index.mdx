Kicbac is a payments platform with SDKs and hosted fields that keep card data out of your servers. Tokenize payment details in the browser with Kicbac.js, send the single-use `payment_token` to your server, then charge it with the Node, Next.js, or Python SDK.

<Warning>
  Never collect raw card numbers, CVV, routing numbers, or account numbers in custom inputs. Use Kicbac hosted fields and send only payment tokens to your server.
</Warning>

<Note>
  New here? Start with [Get your API keys](/credentials). You need a public tokenization key and a secret API key before any quickstart.
</Note>

## Core model

<Steps>
  <Step title="Collect a token">
    Render Kicbac hosted fields in the browser. The browser receives a single-use `payment_token`; raw card data never touches your server.
  </Step>
  <Step title="Charge server-side">
    Send the token to your server and call `transactions.sale` with your secret `KICBAC_SECURITY_KEY`.
  </Step>
  <Step title="Treat declines as data">
    Approved responses are `ok: true`. Declines are typed results, not thrown exceptions. Gateway and processor errors throw.
  </Step>
  <Step title="Verify asynchronous events">
    Webhooks are signed with HMAC-SHA256 over `nonce + "." + rawBody`; verify before parsing or mutating state.
  </Step>
</Steps>
