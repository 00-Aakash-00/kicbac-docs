---
title: "Save Cards with Customer Vault and Stored Credentials"
sidebarTitle: "Save Cards"
description: "Save a tokenized payment method to Kicbac Customer Vault, then run customer-initiated and merchant-initiated follow-up charges using stored credentials."
---

Kicbac Customer Vault stores the payment method from an approved customer-initiated transaction and returns a vault ID. Use that vault ID for future charges without requiring the customer to re-enter payment details. Every follow-up merchant-initiated charge must also reference the original transaction ID.

## Initial customer-initiated transaction

Do not reuse a `payment_token`: it is single-use. The Node SDK can vault the
payment method during the initial sale. With Python, run the sale first and
then create the vault record from the approved transaction ID.

<CodeGroup>

```ts Node
import Kicbac from "kicbac";

const kicbac = new Kicbac();

const initial = await kicbac.transactions.sale({
  amount: "49.99",
  paymentToken: "00000000-000000-000000-000000000000",
  vault: "add",
  initiatedBy: "customer",
  storedCredentialIndicator: "stored"
});

if (!initial.ok || !initial.customerVaultId) {
  throw new Error(initial.ok ? "Vault ID missing" : initial.message);
}
```

```python Python
from kicbac import Kicbac

client = Kicbac()

initial = client.transactions.sale(
    amount="49.99",
    payment_token="00000000-000000-000000-000000000000",
    initiated_by="customer",
    stored_credential_indicator="stored",
)

if not initial.ok:
    raise RuntimeError(initial.message)

vault = client.customers.create(source_transaction_id=initial.transaction_id)
if not vault.ok or not vault.customer_vault_id:
    raise RuntimeError(vault.response_text)
```

</CodeGroup>

Store the initial transaction ID together with the returned vault ID.

## Follow-up merchant-initiated charge

<CodeGroup>

```ts Node
const followUp = await kicbac.customers.charge({
  customerVaultId: initial.customerVaultId,
  amount: "9.99",
  initiatedBy: "merchant",
  storedCredentialIndicator: "used",
  initialTransactionId: initial.transactionId
});
```

```python Python
follow_up = client.customers.charge(
    vault.customer_vault_id,
    amount="9.99",
    initiated_by="merchant",
    stored_credential_indicator="used",
    initial_transaction_id=initial.transaction_id,
)
```

</CodeGroup>

<Warning>
  Do not reuse the payment token or invent either identifier. Use the vault ID and transaction ID returned by this linked flow.
</Warning>
