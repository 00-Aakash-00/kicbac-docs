## Amount simulation

| Amount | Expected result |
| --- | --- |
| `49.99` | Approved, `response=1`, `response_code=100` |
| `1.00` | Approved, `response=1`, `response_code=100` |
| `0.99` | Declined, `response=2`, `response_code=200` |
| `0.05` | Declined, `response=2`, `response_code=200` |

<Warning>
  Do not add real PANs, even expired ones. Use only the published test values above.
</Warning>
