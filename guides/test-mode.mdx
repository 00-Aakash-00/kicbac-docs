---
title: "Test mode"
description: "Use Kicbac test tokens, cards, and amount simulations safely."
---

Use test credentials and test fixtures only. Never place live keys or real payment data in docs, examples, tests, or support tickets. Get your test keys from [Get your API keys](/credentials).

## Test payment tokens

Skip the browser while testing the server: pass these tokens straight to `transactions.sale`.

  `00000000-000000-000000-000000000000`
</ResponseField>

</ResponseField>

## Amount simulation

| Amount | Expected result |
| --- | --- |
| `49.99` | Approved, `response=1`, `response_code=100` |
| `1.00` | Approved, `response=1`, `response_code=100` |
| `0.99` | Declined, `response=2`, `response_code=200` |
| `0.05` | Declined, `response=2`, `response_code=200` |

## Card fixture file

The reusable card, ACH, AVS, CVV, response-code, and amount-simulation fixtures live in `openapi/data/`.

<Warning>
  Do not add real PANs, even expired ones. Use only the published test values above.
</Warning>
