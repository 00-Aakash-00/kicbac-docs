The `recurring.plan.add` event fires immediately after a new recurring plan is successfully created via `kicbac.plans.create()`. Use this webhook to sync newly created plan records to your own database or trigger downstream onboarding workflows.

Event type: `recurring.plan.add`

```json
{
  "event_id": "e88bfc27-2d42-46a1-8427-65b4a7f11f16",
  "event_type": "recurring.plan.add",
  "event_body": {
    "merchant": { "id": "123456", "name": "Test Account" },
    "features": { "is_test_mode": true },
    "id": "1234",
    "name": "my plan",
    "amount": "20.00",
    "day_frequency": null,
    "payments": 8,
    "month_frequency": 9,
    "day_of_month": 10
  }
}
```
