The `recurring.plan.delete` event fires when a recurring plan is permanently removed from the Kicbac dashboard. Use this webhook to clean up or archive plan records in your system. Any active subscriptions tied to the deleted plan should be reviewed immediately.

Event type: `recurring.plan.delete`

```json
{
  "event_id": "e88bfc27-2d42-46a1-8427-65b4a7f11f16",
  "event_type": "recurring.plan.delete",
  "event_body": {
    "merchant": { "id": "123456", "name": "Test Account" },
    "features": { "is_test_mode": true },
    "id": "1234",
    "name": "my plan",
    "amount": "20.00",
    "day_frequency": null,
    "payments": 8,
    "month_frequency": 9,
    "day_of_month": 10
  }
}
```
