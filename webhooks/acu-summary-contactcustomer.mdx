The `acu.summary.contactcustomer` event fires when the Automatic Card Updater (ACU) service flags a vaulted card that requires direct customer follow-up — typically because the card could not be updated automatically and the issuer recommends verifying the new card details with the cardholder directly. Act promptly to avoid failed charges.

Event type: `acu.summary.contactcustomer`

  "event_id": "7bbd4af6-4075-4902-af56-9fc59ab71362",
  "event_type": "acu.summary.contactcustomer",

    "updated_date": "2022-08-23",
    "merchant": { "id": 123456, "name": "Test Account" },
    "cards_checked": {
      "customer_vault": { "checked": 123, "updated": 2 },
      "subscriptions": { "checked": 232, "updated": 1 }
    },
    "vault_updates": [
      {
        "customer_vault_id": "40403043545",
        "billing_id": "34544356",

  }
}
