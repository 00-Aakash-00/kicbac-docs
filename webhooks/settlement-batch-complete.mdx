The `settlement.batch.complete` event fires once per day when the settlement batch finishes processing successfully. The `event_body` includes a breakdown by card type and the full list of settled transaction IDs, making it straightforward to reconcile daily revenue.

Event type: `settlement.batch.complete`

```json
{
  "event_id": "11750910-bd03-4f9a-871a-786203df177f",
  "event_type": "settlement.batch.complete",
  "event_body": {
    "batch_id": "12345678",
    "count": 4,
    "amount": "402.81",
    "merchant": { "id": "123456", "name": "Test Account" },
    "processor": { "id": "ccprocessor", "name": "CC Processor", "type": "cc" },
    "by_card_type": {
      "visa": { "count": 4, "amount": "402.81" }
    },
    "transaction_ids": ["1234000000", "1234000001", "1234000002", "1234000003"]
  }
}
```
