The `settlement.batch.failure` event fires when a daily settlement batch encounters an error during processing. Treat this as a high-priority alert — unsettled transactions may require manual intervention or re-submission. The `event_body` identifies the processor involved to help route the issue to the correct support channel.

Event type: `settlement.batch.failure`

```json
{
  "event_id": "dfe8156d-5dd9-43ac-8928-3cf70ef74108",
  "event_type": "settlement.batch.failure",
  "event_body": {
    "batch_id": "123456",
    "merchant": { "id": "123456", "name": "Test Merchant" },
    "processor": { "id": "ccprocessor", "name": "CC Processor", "type": "cc" }
  }
}
```
