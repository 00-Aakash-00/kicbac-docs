The `transaction.check.status.latereturn` event is sent when an ACH check transaction is returned by the bank *after* it had already appeared to settle. This is sometimes called a late return or a reversal. When you receive this event, the previously settled funds have been clawed back; you should update your records, notify the customer, and handle any downstream fulfilment or accounting adjustments. Deduplicate by `event_id`.

Event type: `transaction.check.status.latereturn`
