sidebarTitle: "void.failure"
description: "Sent when a void fails. Confirm the transaction state before retrying the void or choosing a refund."
openapi: "openapi/kicbac.openapi.json webhook transaction.void.failure"
---

The `transaction.void.failure` event reports that a void was unsuccessful. Verify the signature over the raw request body before parsing, then deduplicate deliveries by `event_id`.

Do not mark the transaction as voided. Query the existing `transaction_id` or `order_id` before retrying the void or choosing a different reversal operation.
