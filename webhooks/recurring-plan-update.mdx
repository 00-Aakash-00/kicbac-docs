The `recurring.plan.update` event fires whenever a recurring plan's properties are modified. The `event_body` always reflects the plan's complete, up-to-date state rather than just the changed fields — compare against your stored copy to determine what changed.

Event type: `recurring.plan.update`

```json
{
  "event_id": "e88bfc27-2d42-46a1-8427-65b4a7f11f16",
  "event_type": "recurring.plan.update",
  "event_body": {
    "merchant": { "id": "123456", "name": "Test Account" },
    "features": { "is_test_mode": true },
    "id": "1234",
    "name": "my plan",
    "amount": "20.00",
    "day_frequency": null,
    "payments": 8,
    "month_frequency": 9,
    "day_of_month": 10
  }
}
```
