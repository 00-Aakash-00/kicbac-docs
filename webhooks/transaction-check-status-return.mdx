The `transaction.check.status.return` event is sent when an ACH check transaction is returned by the customer's bank before settlement — common causes include insufficient funds (NSF), a closed account, or an invalid account number. Use this event to notify the customer, pause fulfilment, and initiate a retry or collections flow. Deduplicate by `event_id`.

Event type: `transaction.check.status.return`
