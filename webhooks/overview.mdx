Kicbac webhooks are HTTPS POST requests with JSON bodies and a `Webhook-Signature` header.

## Verify first

```ts
import { constructEvent } from "kicbac";

const event = constructEvent(rawBody, signatureHeader, signingKey);
```

The signature covers `nonce + "." + rawBody`, where `nonce` is the `t=` value from the header.
