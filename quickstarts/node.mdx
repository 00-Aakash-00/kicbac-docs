Use the `kicbac` package on servers, workers, and other Node 20+ runtimes.

## Prerequisites

- `KICBAC_SECURITY_KEY` set in the server environment (see [Get your API keys](/credentials)).
- A `payment_token` to charge. Your browser app produces one with [Kicbac.js hosted fields](/quickstarts/react); for server-only testing, use the test token `00000000-000000-000000-000000000000`.

<Steps>
  <Step title="Install the package">

```bash
pnpm add kicbac
```

  </Step>
  <Step title="Charge a payment token">

```ts charge.ts
import Kicbac from "kicbac";

const kicbac = new Kicbac();
const orderId = `order_${crypto.randomUUID()}`;

const result = await kicbac.transactions.sale({
  amount: "49.99",
  paymentToken: "00000000-000000-000000-000000000000",
  orderId
});

if (result.ok) {
  console.log("approved", result.transactionId);
} else {
  console.log("declined", result.code, result.message);
}
```

Persist the server-generated `orderId` before the call. A new attempt after a
definitive decline needs a fresh ID and payment token. If the outcome is
ambiguous, do not resubmit; query and reconcile the existing ID first. The ID
is a correlation key, not an idempotency guarantee.

  </Step>
  <Step title="Catch gateway errors">

```ts errors.ts
import Kicbac, { GatewayError } from "kicbac";

const kicbac = new Kicbac();

try {
  const result = await kicbac.transactions.sale({
    amount: "0.99",
    paymentToken: "00000000-000000-000000-000000000000"
  });

  if (!result.ok) {
    console.log("declined result", result.code);
  }
} catch (error) {
  if (error instanceof GatewayError) {
    console.error("gateway error", error.responseCode);
  }
  throw error;
}
```

  </Step>
  <Step title="Run it">

Save the first snippet as `charge.ts` and run it with your `KICBAC_SECURITY_KEY` set:

```bash
pnpm add -D tsx
pnpm tsx charge.ts
```

`49.99` is approved in test mode; `0.99` is declined. See [test mode](/guides/test-mode) for more.

  </Step>
</Steps>
