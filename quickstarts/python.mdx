Use the `kicbac` Python package for sync or async server integrations.

## Prerequisites

- Python 3.10 or newer.
- `KICBAC_SECURITY_KEY` set in the server environment (see [Get your API keys](/credentials)).
- A `payment_token` to charge. Your browser app produces one with [Kicbac.js hosted fields](/quickstarts/react); for server-only testing, use the test token `00000000-000000-000000-000000000000`.

<Steps>
  <Step title="Install the package">

```bash
python -m pip install kicbac
```

  </Step>
  <Step title="Charge a payment token">

```python charge.py
from uuid import uuid4

from kicbac import Kicbac

client = Kicbac()
order_id = f"order_{uuid4().hex}"

result = client.transactions.sale(
    amount="49.99",
    payment_token="00000000-000000-000000-000000000000",
    order_id=order_id,
)

if result.ok:
    print("approved", result.transaction_id)
else:
    print("declined", result.response_code, result.message)
```

Persist the server-generated `order_id` before the call. A new attempt after a
definitive decline needs a fresh ID and payment token. If the outcome is
ambiguous, do not resubmit; query and reconcile the existing ID first. The ID
is a correlation key, not an idempotency guarantee.

  </Step>
  <Step title="Use the async client">

```python async_charge.py
import asyncio

from kicbac import AsyncKicbac


async def main() -> None:
    async with AsyncKicbac() as client:
        result = await client.transactions.sale(
            amount="49.99",
            payment_token="00000000-000000-000000-000000000000",
        )
        print(result.ok)


asyncio.run(main())
```

  </Step>
  <Step title="Run it">

Save the first snippet as `charge.py` and run it with your `KICBAC_SECURITY_KEY` set:

```bash
python charge.py
```

`49.99` is approved in test mode; `0.99` is declined. See [test mode](/guides/test-mode) for more.

  </Step>
</Steps>
