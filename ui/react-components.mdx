`@kicbac/react` gives you three integration options: a drop-in `KicbacPaymentForm` that handles the full checkout flow, a `usePaymentForm` hook for fully custom layouts, and a `KicbacProvider` that supplies your tokenization key and optional appearance settings to whichever component you choose. All options mount Kicbac hosted-field iframes under the hood, so raw card values never appear in your application code.

## Full form

Wrap your checkout UI in `KicbacProvider` and drop in `KicbacPaymentForm` for a ready-made card collection form. Set `amount` in dollars, point `endpoint` at your server-side charge route, and handle the result with `onSuccess` and `onError` callbacks.

```tsx
import { KicbacPaymentForm, KicbacProvider } from "@kicbac/react";
import "@kicbac/react/styles.css";

export function Checkout() {
  return (
    <KicbacProvider
      tokenizationKey={process.env.NEXT_PUBLIC_KICBAC_TOKENIZATION_KEY}
      injectStyles={false}
    >
      <KicbacPaymentForm
        amount="49.99"
        endpoint="/api/pay"
        collectCvv
        buttonLabel="Pay securely"
        onSuccess={(payment) => console.log(payment.transactionId)}
      />
    </KicbacProvider>
  );
}
```

## Headless fields

Use the `usePaymentForm` hook when you need full control over layout, styling, or field order. `getFieldProps` returns the props needed to mount each hosted iframe, and `isValid` reflects whether all required fields have been filled.

```tsx
import { KicbacProvider, usePaymentForm } from "@kicbac/react";
import "@kicbac/react/styles.css";

function HeadlessFields() {
  const form = usePaymentForm({ amount: "49.99", endpoint: "/api/pay" });

  return (
    <form onSubmit={(event) => { event.preventDefault(); void form.submit(); }}>
      <div {...form.getFieldProps("ccnumber")} />
      <div {...form.getFieldProps("ccexp")} />
      <div {...form.getFieldProps("cvv")} />
      <button disabled={!form.isValid}>Pay</button>
    </form>
  );
}

export function HeadlessCheckout() {
  return (
    <KicbacProvider
      tokenizationKey={process.env.NEXT_PUBLIC_KICBAC_TOKENIZATION_KEY}
      injectStyles={false}
    >
      <HeadlessFields />
    </KicbacProvider>
  );
}
```

The headless hook still mounts Kicbac hosted-field iframes. It does not expose raw card values.
