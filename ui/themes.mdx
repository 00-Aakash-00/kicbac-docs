---
title: "Kicbac Appearance and Themes: Customize Your Payment UI"
sidebarTitle: "Themes"
description: "Use @kicbac/themes and createTheme() to customize colors, typography, and border radii across all Kicbac hosted fields and the pre-built payment form."
---

Kicbac ships with sensible brand defaults — Inter font, `#141442` indigo text, `#f04ac4` pink accent, 10 px field radii, and 16 px card radii — but you can override any of these through the `appearance` prop on `KicbacProvider`. Pass a theme object built with `createTheme()` from `@kicbac/themes`, and every hosted field and payment form component rendered inside that provider will pick up your design tokens automatically.

```tsx
import { KicbacPaymentForm, KicbacProvider } from "@kicbac/react";
import { createTheme } from "@kicbac/themes";

const appearance = createTheme({
  variables: {
    colorPrimary: "#f04ac4",
    colorText: "#141442",
    gradientCta: "linear-gradient(280deg, #f8b345 -25%, #f23fe5 34.64%, #ad4ef8 62.57%, #6dacff 109%)"
  }
});

export function Checkout() {
  return (
    <KicbacProvider
      tokenizationKey={process.env.NEXT_PUBLIC_KICBAC_TOKENIZATION_KEY}
      appearance={appearance}
    >
      <KicbacPaymentForm amount="49.99" endpoint="/api/pay" />
    </KicbacProvider>
  );
}
```

To use the built-in defaults without modification, import `defaultTheme` from `@kicbac/themes` and pass it directly to `appearance`. Any variables you omit from `createTheme` fall back to these same defaults.
