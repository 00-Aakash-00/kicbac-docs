# Contributing

Thanks for improving Kicbac's docs.

## Preview

```sh
pnpm run dev
```

## Checks

```sh
pnpm run broken-links
pnpm run validate
pnpm run a11y
pnpm run build
```

## Style

- Keep pages concise and task-oriented.
- Use second person.
- Use language tags on code blocks.
- Keep internal links root-relative and omit file extensions.
- Do not invent SDK methods. Match package READMEs and exports.
- Do not document real card numbers, live keys, or raw-card server flows.
