# Kicbac Docs

Mintlify documentation for the Kicbac developer platform.

## Local preview

```bash
pnpm install
pnpm run dev
```

## Verification

```bash
pnpm run broken-links
pnpm run validate
pnpm run a11y
pnpm run build
```

The generated API reference uses the canonical OpenAPI file at `openapi/kicbac.openapi.json`.
