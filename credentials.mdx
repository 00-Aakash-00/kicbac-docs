This is the first thing to do. Before any quickstart, you need a Kicbac account and your API keys. This page covers **what you need**, **where to get each piece**, and **how to wire it up** so the SDKs pick everything up automatically.

## 1. Create your account

[Sign up for Kicbac](https://kicbac.com) and sign in to your dashboard. New accounts start in **test mode**, so you can build and run the entire payment flow with test cards before you accept a single real payment. You don't need to talk to sales or get approved to start building.

## 2. Get your three keys

Kicbac uses three keys. One is **public** (safe to ship in your browser bundle) and two are **secret** (server-only). All three are in your dashboard under **Settings → Security Keys** and **Settings → Webhooks**.

<Columns cols={1}>
  <Card title="Tokenization key — public" icon="globe">
    **Used in:** browser code (React, Next.js, vanilla JS).

    **What it does:** lets Kicbac hosted fields turn a customer's card or bank details into a single-use `payment_token`, so raw data never reaches your server. Safe to expose in a client bundle.

    **Where to get it:** dashboard → **Settings → Security Keys → Public keys**, with the **Tokenization** permission. Copy the key value.
  </Card>
  <Card title="API key (security key) — secret" icon="lock">
    **Used in:** your backend only (Node, Python, Next.js route handlers).

    **What it does:** authenticates your server to charge tokens, refund and void, manage saved cards, run subscriptions, and pull reports.

    **Where to get it:** dashboard → **Settings → Security Keys → Private keys**. Generate one if you don't have it. **Never** put this in browser code or commit it.
  </Card>
  <Card title="Webhook signing key — secret" icon="webhook">
    **Used in:** your webhook endpoint only.

    **What it does:** proves that an incoming webhook is genuinely from Kicbac and was not tampered with.

    **Where to get it:** dashboard → **Settings → Webhooks** (shown when you add an endpoint).
  </Card>
</Columns>

<Note>
  You only need the tokenization key and the security key to take your first payment. Add the webhook signing key when you start [receiving webhooks](/webhooks/overview).
</Note>

## 3. Set them as environment variables

The SDKs read these exact variable names automatically, so you never hard-code a key. Use test keys while you build.

<CodeGroup>
```bash Next.js (.env.local)
# Public — exposed to the browser
NEXT_PUBLIC_KICBAC_TOKENIZATION_KEY=your_public_tokenization_key

# Secret — server only
KICBAC_SECURITY_KEY=your_secret_api_key
KICBAC_WEBHOOK_SIGNING_KEY=your_webhook_signing_key
```

```bash React + Vite (.env)
# Public — exposed to the browser
VITE_KICBAC_TOKENIZATION_KEY=your_public_tokenization_key
```

```bash Node / Python (.env)
# Secret — server only
KICBAC_SECURITY_KEY=your_secret_api_key
KICBAC_WEBHOOK_SIGNING_KEY=your_webhook_signing_key
```
</CodeGroup>

How each SDK reads them:

| Variable | Public? | Read by |
| --- | --- | --- |
| `NEXT_PUBLIC_KICBAC_TOKENIZATION_KEY` / `VITE_KICBAC_TOKENIZATION_KEY` | Public | `<KicbacProvider>` and `loadKicbac()` in the browser |
| `KICBAC_SECURITY_KEY` | Secret | `new Kicbac()` (Node) and `kicbac.Kicbac()` (Python) |
| `KICBAC_WEBHOOK_SIGNING_KEY` | Secret | `kicbacWebhookHandler()` (Next.js) reads it automatically; pass it explicitly to `constructEvent` / `construct_event` in the Node and Python SDKs |

<Warning>
  Only the tokenization key is public. Keep `KICBAC_SECURITY_KEY` and `KICBAC_WEBHOOK_SIGNING_KEY` on your server: never commit them, log them, or expose them in browser code.
</Warning>

## 4. Confirm it's wired up

A quick check that your secret key is loaded (test mode never moves real money):

<CodeGroup>
```ts Node
import Kicbac from "kicbac";

// Reads KICBAC_SECURITY_KEY from the environment.
const kicbac = new Kicbac();
const result = await kicbac.transactions.sale({
  amount: "49.99",
  paymentToken: "00000000-000000-000000-000000000000" // test token
});
console.log(result.ok ? "key works — approved" : `declined: ${result.message}`);
```

```python Python
import kicbac

client = kicbac.Kicbac()  # reads KICBAC_SECURITY_KEY
result = client.transactions.sale(
    amount="49.99",
    payment_token="00000000-000000-000000-000000000000",  # test token
)
print("key works — approved" if result.ok else f"declined: {result.message}")
```
</CodeGroup>

If you get an authentication error, the security key isn't set or is wrong. See [test mode](/guides/test-mode) for the full list of test tokens, cards, and amount simulations.
